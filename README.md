## ✨ Features

- **Full-Screen Cinematic Hero**: Editorial photography, staggered reveals, and animated flight path SVG.
- **Atmospheric Aeronautical Aesthetic**: Boarding-pass motif, compass rose, telemetry labels, and midnight-navy/gold palette.
- **Editorial About & Pillars**: Factual presentation of academic pursuit, discipline, and milestones.
- **Personal Chronology**: Minimal timeline tracing her origin to active aviation studies.
- **Curated Asymmetric Gallery**: Fullscreen lightbox with keyboard navigation and smooth transitions.
- **Direct Contact Suite**: Integrated email, phone, and Instagram touchpoints.
- **Performant & Responsive**: Zero layout shifts, hardware-accelerated animations, and tailored mobile drawer.
